# Props란?

Props는 부모 컴포넌트가 자식 컴포넌트에게 데이터를 물려주는 방법입니다.

- Props는 **읽기 전용**이며, 자식은 절대 props를 직접 수정해서는 안 됩니다.  
  (Top-Down 데이터 흐름)

- Props는 HTML 속성처럼 `<Component propName="값" />` 형태로 전달합니다.

- 문자열이 아닌 데이터(숫자, 배열 등)는 `{}` 중괄호로 감싸서 전달해야 합니다:  
  `age={30}`

- 자식 컴포넌트에서는 함수의 파라미터에서 구조 분해 할당  
  `({ propName }) => ...`  
  을 사용해 props를 받는 것이 편리합니다.
