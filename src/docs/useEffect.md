# 컴포넌트의 생명주기와 부수 효과: useEffect

React 컴포넌트의 주된 임무는 state와 props를 기반으로 UI를 그리는(렌더링) 것입니다.  
하지만 때로는 렌더링과 직접적인 관련이 없는 다른 작업들이 필요합니다.

- 서버에서 데이터 가져오기 (API 호출)
- 외부 라이브러리(ex: 차트) 연동하기
- 타이머 설정 및 해제하기 (setInterval)

이처럼, 렌더링 결과에 영향을 주지 않는 모든 부수적인 작업을 **부수 효과(Side Effect)**라고 부릅니다.  
그리고 **useEffect**는 함수형 컴포넌트에서 이러한 부수 효과를 처리하기 위해 사용하는 Hook입니다.

---

## 1. 컴포넌트의 생명주기(Lifecycle)

useEffect를 이해하려면 먼저 컴포넌트의 간단한 생명주기를 알아야 합니다.  
컴포넌트는 다음과 같은 생애를 보냅니다.

- **탄생 (Mount)**: 컴포넌트가 처음 생성되어 화면에 나타나는 단계
- **성장/변화 (Update)**: Props나 State가 변경되어 컴포넌트가 다시 그려지는(리렌더링) 단계
- **소멸 (Unmount)**: 컴포넌트가 화면에서 사라지는 단계

useEffect는 이 생명주기의 특정 시점에 우리가 원하는 코드를 실행할 수 있게 해줍니다.

---

## 2. useEffect의 기본 형태와 사용법

useEffect의 기본 구조는 다음과 같습니다.

```jsx
import { useEffect } from 'react';

useEffect(() => {
  // 실행하고 싶은 부수 효과 코드
}, [의존성 배열]);
```

- 첫 번째 인자(콜백 함수): 실행하고 싶은 부수 효과 코드를 담는 함수입니다.
- 두 번째 인자(의존성 배열): useEffect의 실행 시점을 결정하는 가장 중요한 부분입니다.  
  이 배열에 어떤 값을 넣느냐에 따라 useEffect의 동작 방식이 달라집니다.

---

## 3. 의존성 배열(Dependency Array)

의존성 배열을 어떻게 설정하느냐에 따라 useEffect는 세 가지 방식으로 동작합니다.

### 1️⃣ 의존성 배열을 생략하는 경우 (매 렌더링마다 실행)

```jsx
useEffect(() => {
  console.log("컴포넌트가 렌더링될 때마다 실행됩니다.");
});
```

컴포넌트가 처음 렌더링될 때, 그리고 state나 props가 바뀌어 리렌더링될 때마다 매번 실행됩니다.  
의도치 않은 무한 루프를 유발할 수 있어 거의 사용하지 않습니다.

---

### 2️⃣ 빈 배열 [] 을 전달하는 경우 (최초 1회만 실행)

```jsx
useEffect(() => {
  console.log("컴포넌트가 처음 화면에 나타날 때(mount) 한 번만 실행됩니다.");
  // 주로 최초 데이터 로딩, 외부 라이브러리 초기 설정 등에 사용됩니다.
}, []);
```

가장 흔하게 사용되는 방식입니다.  
컴포넌트가 처음 화면에 나타날 때 딱 한 번만 실행됩니다.  
서버에서 초기 데이터를 가져올 때 이상적입니다.

---

### 3️⃣ 배열에 특정 값 [value] 을 전달하는 경우 (특정 값이 변할 때만 실행)

```jsx
const [count, setCount] = useState(0);

useEffect(() => {
  console.log(`count 값이 변경되었습니다: ${count}`);
}, [count]);
```

처음 화면에 나타날 때 한 번 실행되고, 그 이후에는 의존성 배열 안의 값(count)이 변경될 때만 실행됩니다.  
특정 prop이나 state의 변화에 반응하여 어떤 작업을 수행해야 할 때 사용합니다.

## 4. 클린업(Cleanup) 함수

클린업 함수는 매우 중요합니다.  
만약 타이머를 정리하지 않으면, Timer 컴포넌트가 화면에서 사라져도 타이머는 계속 백그라운드에서 동작하여 메모리 누수(memory leak)를 일으킬 수 있습니다.  
useEffect는 return 값으로 함수를 지정하여 컴포넌트가 사라지기 직전에 실행될 코드를 예약할 수 있습니다.

```jsx
useEffect(() => {
  const timer = setInterval(() => {
    console.log("타이머 동작 중...");
  }, 1000);

  // 컴포넌트가 언마운트될 때 타이머를 정리하는 클린업 함수 반환
  return () => {
    clearInterval(timer);
    console.log("타이머 정리 완료!");
  };
}, []);
```
